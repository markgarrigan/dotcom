Story

Plainwork was an experiment in how small a useful app can be: four macOS menu bar apps, each a single Swift file with no SwiftUI. Paper is for plain-text notes, Rated for quick 0 to 5 ratings, Taken for appending the clipboard to notebooks, and Timed for timers.

Alongside them is tkn, a Bash CLI for Markdown notebooks with search, date queries and git sync. Everything ships through Homebrew without a paid Apple developer account, which keeps the apps free.

Results

  • ✓Four apps and a CLI shipped in two weeks, December 29, 2025 to January 10, 2026.
  • ✓Each installs with brew.

Decisions

  1. 01

    One file per app

    Each app is a single main.swift on Cocoa, without SwiftUI or an Xcode project.

  2. 02

    Plain text files

    Ratings and notebooks are text files in your home folder. You can read them, grep them and back them up.

  3. 03

    Free means unsigned

    “To keep these apps free, we don't use an Apple Developer account, so macOS may quarantine them.” The site gives the one command that clears it.
